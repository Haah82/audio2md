Implementation notes

Cập nhật: 18/09/2026

Quyết định triển khai

  • Security: Không đọc, in, ghi, hoặc đưa API key vào log, test, HTML hay tài liệu. Output chỉ dùng nhãn biến môi trường và tier.
  • Secret archive: Thêm env.zip vào .gitignore vì workspace có archive cấu hình không được commit. File không bị mở, thay đổi hay xóa.
  • Live probe là opt-in: check_api.py chỉ list model mặc định; --probe mới gọi generate_content. Quyết định này tránh phát sinh request/billing ngoài ý muốn.
  • 503: Xem là lỗi tạm thời của service/model, retry với exponential backoff trên FREE tier và không rơi sang PAID chỉ vì 503.
  • Model discovery: Không tự đoán fallback. Model chính/fallback chỉ lấy từ GEMINI_MODEL và GEMINI_FALLBACK_MODELS.
  • 404 classification: Chỉ đánh dấu model hỏng khi message vừa chỉ ra 404/not found vừa có từ model; lỗi file upload 404 không được phép vô hiệu hóa model.
  • Existing test suite: Các test cũ import những module không tồn tại trong src/ hiện tại. Đã thêm test độc lập cho gemini_pool; không sửa/xóa test cũ vì đó là thay đổi ngoài phạm vi.
  • Verification blocker: Không chạy được unit test trong workspace: .venv\Scripts\python.exe trỏ tới Python base interpreter không còn truy cập được. Không chạy live check_api.py để tránh gọi API khi local runtime đang lỗi.
